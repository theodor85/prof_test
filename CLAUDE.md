# CLAUDE.md

Профориентационный тест для детей: SPA на TypeScript + React 19 + Vite + Tailwind CSS v4, пакетный менеджер pnpm.
Язык интерфейса и комментариев — русский.

## Команды

```bash
pnpm dev      # dev-сервер
pnpm build    # tsc -b + vite build — запускать для проверки типов
pnpm lint     # oxlint
```

Тестов нет.

Деплой: `.github/workflows/deploy.yml` при пуше в `main` запускает lint и build и выкладывает `dist` на Cloudflare Pages (проект `prof-test`, wrangler запускается через `npx`). Нужны секреты `CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`.

## Как устроено

Маршрутизации нет: `src/App.tsx` хранит текущий экран в `useState` (`start` → `quiz` → `result`). С `start` можно сразу открыть `result` из списка пройденных тестов.

- `src/data/data.json` — данные теста, ключи `12years` и `9years`, в каждом `variants` (`description`, `scale`) и `scales` (`id`, `name`, `character`, `description`). `variant.scale` ссылается на `scale.id`.
- `src/lib/test.ts` — типы, загрузка данных, `makePairs` и подсчёт очков.
- `src/screens/` — экраны: старт (выбор возраста и список пройденных тестов), пары, результат.
- `src/lib/history.ts` — история в IndexedDB (база `prof_test`, хранилище `results`). Хранятся только `createdAt`, `age` и `result`; тексты и персонажи берутся из текущего `data.json`. Если меняете структуру записи, поднимите `DB_VERSION` и добавьте миграцию в `onupgradeneeded`.
- `src/components/ClassIcon.tsx` — SVG-иконки классов (эмблема на цветном круге), по одной на id шкалы. Персонажи с одинаковым id совпадают в обоих возрастах. Цвета классов — в `src/lib/classColors.ts`. Для новой шкалы нужно добавить эмблему и цвет, иначе будет серый круг с первой буквой.

## Правила теста

- Все варианты случайно разбиваются на пары, каждый вариант используется ровно один раз; в паре не может быть двух вариантов одной шкалы. `makePairs` всегда начинает пару со шкалы с наибольшим остатком — так разбиение не заходит в тупик, пока ни одна шкала не занимает больше половины вариантов. Если меняете данные, соблюдайте это условие и чётное число вариантов.
- Результат хранится в виде `{ scales: [{ scale: <id>, score }] }`: все шкалы начинают с 0, выбранный вариант даёт +1 своей шкале.
- Класс определяет `classify` в `src/lib/test.ts`:
  - лидер опережает второе место на 2 очка и больше — один класс;
  - лидер опережает второе место ровно на 1 очко — основной класс, а все шкалы со вторым результатом становятся подклассами;
  - несколько шкал делят первое место — «Твой класс — X или Y», подклассы не учитываются.
- Экран результата: «Твой класс» (иконки и описания `scale.description` для основных классов и подклассов), затем «Детальные результаты» — горизонтальная столбчатая диаграмма цветами классов с подписями `scale.character` и числом очков, по убыванию очков, и кнопка «Пройти заново».
- Результат сохраняется в IndexedDB только после завершения теста; прерванный тест не сохраняется.
- На стартовом экране под кнопками возраста — «Пройденные тесты», новые сверху. В строке: дата и время, возраст и только иконки (основной класс крупнее, подклассы мельче, при ничьей все крупные). При наведении мыши на иконку появляется тултип с именем класса; на сенсорных экранах тултипа нет — имена видны на экране результата. Кнопка «×» удаляет запись после подтверждения. По нажатию на строку открывается тот же экран результата с подзаголовком «возраст · дата» и кнопкой «К списку» вместо «Пройти заново».
- Кнопки «Назад» на экране пар нет — это сделано намеренно.
- Ребёнку пишем на «ты».

## Стиль

- Импорт из `src` через алиас `@/`.
- Mobile first: стили без префикса для телефонов, `sm:`/`md:` для экранов шире; учтены safe-area отступы и тёмная тема (`dark:`).
- Цвета бренда — `brand-*` в `@theme` в `src/index.css`.
